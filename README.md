# 🧹 SafeCleaner

> **Storage Sense-style Safe Storage Cleaner built with PyQt5 & Multi-threading**

Windows의 고질적인 임시 파일(Temp)과 주요 브라우저의 캐시 데이터를 안전하고 빠르게 소거하여 디스크 공간을 확보하는 **데스크톱 다이어트 어플리케이션**입니다. 

단일 스레드 파일 삭제 방식의 한계를 극복하기 위해 **멀티스레딩(ThreadPoolExecutor)** 구조를 도입하여, 수십만 개의 자잘한 캐시 파일도 GUI 멈춤(응답 없음) 현상 없이 초고속으로 진압합니다.

---

## ✨ 핵심 기능 (Key Features)

- **안전한 화이트리스트 필터링:** 시스템에 치명적인 실행 파일 및 라이브러리(`.exe`, `.dll`, `.sys`, `.bat` 등)는 소스 레벨에서 완벽하게 필터링되어 절대 지워지지 않습니다.
- **초고속 멀티스레드 삭제:** `ThreadPoolExecutor`를 활용해 최대 16개의 워커 스레드가 동시 다발적으로 소거 작업을 수행합니다. (80만 개 이상의 파일도 랙 없이 처리 가능)
- **비동기 스캔 및 실시간 시각화:** 스캔 및 정리 실행 시 GUI 스레드와 연산 스레드를 분리하여, 프로그레스 바(Progress Bar)를 통해 진행 상황을 실시간 퍼센트(%)로 매끄럽게 안내합니다.
- **Windows 11 Fluent 다크 테마:** 눈이 편안한 미드나잇 다크 색상과 세련된 블루 포인트 컬러를 적용하여 직관적인 UX를 제공합니다.
- **지능형 권한 제어:** VS Code 등 개발 환경(디버깅 모드)에서는 부드럽게 무시하고, 최종 배포용 단독 `.exe` 구동 시에는 자동으로 관리자 권한(UAC) 상승 팝업을 요청합니다.
